# Independent mission critique — round 3

Reviewed 2026-10-17, before the implementation's post-review practice-flow changes. Scope: **this single three-part mission**, its Broodkeeper miniboss and Furnace Warden. The gates, authored combinations, opening shutters and per-part reports are worthwhile improvements. This is now a strong, complete shooter mission. My score is **8.72/10 mean**; **two categories exceed 8.8**. The requested every-category-above-8.8 outcome is **not established**. Scores are editorial judgments, not adjusted to pass a gate. Campaign size and production budget are not deductions.

## Remaining work with the highest value

1. **Make practice feedback describe the selected flight.** The captured part-03 practice debrief correctly labels itself practice and protects full-run records, but shows a full-run C, `RELAY DATA 0 / 3`, and “Recover all three courier relays.” Only one courier is available from that entry. This is a confirmed UI/content defect even though its completion was synthetic. Use a practice-specific grade or mastery label, an available-relay denominator, an attainable part-focused target, and a primary replay action that preserves the selected practice start. Source currently routes `replay` through only difficulty/weapon, so it starts a full mission. The explicit `Practice from 03` button does preserve part 03.

2. **Make the optional foundry route impose the trade the instruction promises.** This is source-derived design analysis, not a collision or fairness bug. The low-opening gate starts at 10s, x1500, and travels at 220 units/s; it leaves x=-80 at about **17.18s**. The optional upper courier arrives at **21s**, after that gate is gone. The next gate starts at **27s** with an opening centered at **y250**, broadly favoring the courier's **y200** lane. Both vents aim at the player's current lane. The comms therefore describe a more concrete safe-low/risky-upper choice than the geometry establishes. Adjust the timing/coverage of this existing encounter so the reward visibly competes with a concurrently safer passage, then retain a recovery beat. More enemy types or a longer stage are unnecessary.

3. **Separate combatant silhouettes from the moving machinery.** This is a visual judgment supported by [normal-time part 02](evidence/critic-round-3/part2-natural-time-checkpoint.png), not the old foreground-depth bug. A restrained rim/outline or local contrast reduction behind action would help dark drones, anglers and the player remain recognizable over bronze gears. Preserve the attractive art and the clear warning/shot palette. Verify native phone size during active combat, rather than only enlarging HUD text again.

4. **Finish the perceptual and delivery checks before claiming the remaining polish.** Listen to sustained fire, a Guard/counter exchange, simultaneous warnings, a core opening and overload. Judge whether the ducking preserves useful cues and whether the single-loop treatment gives the finale enough musical payoff; only then decide whether more audio is needed. Run an ordinary fully rendered mission on a representative desktop and phone, with frame pacing and two-thumb Focus/Guard use observed. A short first-play/replay observation would also test whether the intended choices are understood and invite another attempt. These are missing evidence, not proof of poor audio or slow performance.

The useful R-Type/Gradius execution comparison is whether positioning, defense, commitment and recovery create memorable decisions inside this one stage. This revision moves substantially toward that standard. It does not establish objective addictiveness, superiority to either reference, or a truthful all-categories-above-8.8 scorecard.
